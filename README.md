# -Digital-Music-Store-Data-Analysis-using-SQL
Analysis using sql


Analyzed a relational database of a digital music store containing tables like customers, invoices, tracks, genres, artists, and sales.

Wrote complex SQL queries to extract insights on customer behavior, regional sales performance, and music genre popularity.

Identified top-selling artists, albums, and tracks based on purchase history and download frequency.

Performed segmentation of customers by country, purchase patterns, and lifetime value.

Used SQL functions (JOINs, CTEs, subqueries, GROUP BY, HAVING, CASE) to solve business questions.

Created views and optimized queries to improve performance and data accessibility.

Provided actionable recommendations to improve sales and marketing strategies.
